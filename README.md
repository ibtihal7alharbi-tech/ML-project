## 📖 Overview

Sleep plays a vital role in physical health, mental well-being, cognitive performance, and overall quality of life. Yet many individuals struggle with poor sleep habits, hidden sleep-related risks, and limited awareness of how lifestyle factors influence their sleep outcomes.

This project presents an **AI-Powered Sleep Health Prediction and Recommendation System** that combines:

- **Machine Learning**
- **Interactive Exploratory Data Analysis (EDA)**
- **Personalized Recommendations**
- **Scenario Simulation**
- **User-Friendly Streamlit Deployment**

Rather than functioning as a simple machine learning notebook, the project is designed as a **complete intelligent system** that helps users better understand their sleep condition, identify risk factors, and take actionable steps toward improvement.

---

## ❗ Problem Statement

Sleep-related issues often go unnoticed until they begin to affect energy levels, mood, focus, productivity, and long-term health. Many existing tools provide charts or raw metrics, but they rarely offer clear interpretation or practical next steps that users can immediately benefit from.

Our project addresses this gap by building a smart system that can:

- predict important sleep-related outcomes,
- analyze health and lifestyle patterns,
- provide personalized recommendations,
- and guide users toward better sleep habits through an engaging and intuitive digital experience.

---

## 🎯 Objectives

The main objectives of this project are to:

- Build a smart and visually compelling sleep health platform
- Perform meaningful and interactive exploratory data analysis
- Predict multiple sleep-related targets using machine learning
- Transform predictions into practical, personalized recommendations
- Create a complete user experience rather than a simple technical dashboard
- Support healthier lifestyle decisions through AI-powered insights

---

## 💡 Why This Project Matters

This project goes beyond pure prediction and focuses on **real user value**.

It helps answer important questions such as:

- Am I at risk of a sleep disorder?
- How good is my sleep quality likely to be?
- How might my habits affect my cognitive performance?
- Am I likely to feel rested?
- What changes should I make to improve my sleep health?

By combining predictive intelligence with actionable recommendations, the system becomes more useful, more practical, and more impactful for real users.

## ✨ Key Features

### 1. Interactive and Engaging EDA
The application includes a rich Exploratory Data Analysis experience with attractive and informative visualizations that help users understand:

- data distributions,
- feature relationships,
- behavioral patterns,
- and health-related trends.

### 2. Multi-Target Prediction
Instead of predicting only one outcome, the system predicts several key sleep-health targets to provide a more comprehensive and realistic picture of the user’s condition.

### 3. AI-Driven Personalized Recommendations
The platform generates tailored recommendations based on predicted results, user habits, and potential risk indicators.

### 4. Scenario Simulator
Users can explore how improving specific lifestyle habits may influence their sleep outcomes and overall well-being.

### 5. Premium User Experience
The application is designed as a polished, competition-grade platform with strong attention to visual appeal, usability, and clarity.

### 6. Holistic Sleep Health View
The system also provides a combined summary perspective through an **Overall Sleep Health Index** for a more complete interpretation of user condition.

## 🏗️ System Architecture

The project can be viewed as an integrated system composed of the following modules:

### Data Preprocessing Module
Responsible for cleaning and preparing the dataset for analysis and model training.

### Exploratory Analysis Module
Provides rich visual insights into health, sleep behavior, and feature relationships.

### Prediction Engine
Uses machine learning models to estimate sleep-related outcomes from user inputs and behavioral indicators.

### Recommendation Engine
Transforms predictions into actionable, understandable, and personalized guidance.

### Scenario Simulation Module
Allows users to test healthier lifestyle adjustments and observe their possible effects.

### Streamlit User Interface
Serves as the front-end experience where analytics, predictions, and recommendations are presented in an intuitive and visually engaging format.
